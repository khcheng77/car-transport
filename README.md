# 車輛派遣系統整合 — 互動原型

依 [`docs/PLAN.md`](docs/PLAN.md) 建置的**可動版雛形**，用來和業務單位逐項確認流程與規則。
純 HTML + JavaScript，**無資料庫、無後端**，直接用瀏覽器開啟即可操作；資料存在記憶體，重新整理頁面即重置。

> 正式版技術棧為 .NET Framework 4.8 / ASP.NET MVC（見 PLAN.md 第 1 節）。本原型只驗證流程、規則與畫面，不是正式程式碼。
> 原型數值（路程表、天數表、浪費係數、站內額度、緩衝時間等）多為示意值，待業務盤點，不可直接上線。

## 架構：四個作業模組＋共用單元

| 模組 | 申請（使用者） | 單位主管審核 | 派車調度（業務） | 運輸主管簽審 | 車輛異動實登（業務） | 駕駛任務單（駕駛） |
|---|---|---|---|---|---|---|
| A 巡迴財物轉運 | ✔（送出即自動媒合班次） | —（免審） | 車次追蹤／異動、路線與班次 | — | ✔（以車次為單位） | ✔ |
| B 院區財物轉運 | ✔ | ✔ | ✔（依派車日媒合產生派車單） | ✔ | ✔（以派車單為單位） | ✔ |
| C 人員運輸 | ✔ | ✔ | ✔（依出發日期批次媒合產生派車單） | ✔ | ✔（以派車單為單位） | ✔ |
| D 一般用車 | ✔（含例行用車類別） | ✔ | ✔（一單一派車單） | ✔ | ✔（以派車單為單位） | ✔ |

共用單元：**申請引導**（依填寫內容判定該走哪一種申請並帶入資料）、**系統儀表板**、**裝載判定引擎**、**主檔資料**。

- **A 巡迴財物轉運**：院區內固定路線（站點 100～900）、每小時一班；申請送出即自動排入最近可行班次並告知時間與車號，排不進為「待調度」，由業務於車次追蹤／異動改派或無車退回。
- **B 院區財物轉運**：南北 10 院區一直線，幹線車沿線收送；調度依派車日媒合派車（去程貪婪／直達／回程），派車單送運輸主管簽審，通過才生效。危險品運輸限派可載危險品車輛。
- **C 人員運輸**：共乘清單內的出發地／目的地，依出發日期批次媒合併車（來回單／單程單），考量座位、車型、保修、駕駛請假與工時。
- **D 一般用車**：不限地點的用車，可自駕；調度人工確認資源後派車，派車判斷即產生派車單並送簽審。

## 申請單狀態（四模組一致，`js/flow.js`）

`申請中 → 待二級審 →（退回修編）→ 待調度 →（無車退回）→ 調度中 → 調度主管審 → 待出車 → 已出車 → 已回登`，另有 `已刪除`（申請人撤單）。

- 沒有的關卡就跳過：A 無二級審與調度主管；D 一單一派車單，無「調度中」。
- **退回修編**：單位主管退回，或派車調度退回使用者修改（B／C／D，可批次）；申請人修改後重送需再經單位主管審核。
- **撤單**：車輛出發日前一天（含）以前，申請人可在申請明細頁撤單（原因必填）；已派車、已簽審者亦可，系統自動釋放車輛與駕駛。
- **已回登**：完成車輛異動實登（起訖里程，另可填加油公升數、駕駛工時、駕駛加班時數）。

## 裝載判定（A、B、申請引導同一套）

條件為「**財物不堆疊、能夠裝入的最大量**」（`js/loadengine.js`）：

1. 每件平放、只能水平轉向——高不超過車廂高，底面（長寬可互換）放得進車廂地板。
2. 有效地板面積＝Σ（長×寬×件數×類別浪費係數），不超過車廂地板（車長×車寬）。
3. 合計重量不超過載重。等於上限仍算裝得下。

B 的派車容量取沿途峰值（每站先卸後裝）；申請引導以收貨日巡迴空車試裝判斷該走 A 或 B。

## 畫面慣例

各單元採「查詢頁 → 明細頁／新增頁」：上半查詢條件（右上「查詢」「新增」），下半 grid，點「明細」進入細節。
表單欄位以 masonry 資訊卡排版，是／否題用同列緊湊單選。完整規範見 [`docs/UI-CONVENTIONS.md`](docs/UI-CONVENTIONS.md)。

## 如何執行

直接用瀏覽器開啟 `index.html`（不需架站、不需安裝套件）。推送到 `main` 時由 `.github/workflows/deploy-pages.yml` 自動部署 GitHub Pages。

## 測試

純 Node、零相依的回歸測試，固化 Guardrails 與歷次修正（目前 276 項）：

```
node tests/guardrails.test.js
```

每次 push / PR 由 `.github/workflows/tests.yml` 自動執行。

## 專案結構

```
index.html             主框架（側邊導覽＋頁面容器）
css/styles.css         設計系統
js/data.js             主檔與示範資料（院區／站點／車輛／駕駛／路程表／係數／保修／請假／三聯單單號示意）
js/loadengine.js       共用裝載判定引擎（不堆疊）
js/flow.js             申請單狀態推導、撤單、退回修改（四模組共用）
js/signoff.js          運輸主管簽審（B／C／D 共用）
js/usage.js            車輛異動實登（四模組共用）
js/guide.js            申請引導（判定決策表、帶入資料、引導紀錄）
js/moduleA.js          模組 A：巡迴財物轉運（班次媒合）
js/moduleB.js          模組 B：院區財物轉運（媒合派車、派車單）
js/moduleC.js          模組 C：人員運輸（批次媒合、派車單）
js/moduleD.js          模組 D：一般用車（資源檢核、一單一派車單）
js/app.js              前端控制器（導覽、畫面、互動）
js/vendor/             masonry（本地檔，不連外）
tests/                 guardrails.test.js 與 Node 載入器
docs/                  規格與文件（見下）
```
